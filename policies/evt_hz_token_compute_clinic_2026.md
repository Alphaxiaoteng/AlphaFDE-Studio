# 2026 西湖区算力券与“Token券”现场申领兑付辅导专场（云谷中心站）

> 公开活动样例，非正式全文。官方出处：https://www.hzxh.gov.cn/

**渠道**：公开活动  ·  **赛道**：补贴类/现场申报辅导
**文号/版本**：西湖企事通便民专场通知
**窗口/活动时间**：2026-09-29 · 云谷中心企服大厅 · 预约取号中（2026-09-29 ~ 2026-09-29

## 一句话
经信专员驻场辅导：手把手指导导出大模型 API 日志、发票归集，现场审核直报 50% Token 补贴与 100 万算力券

## 出处摘要
西湖区经信局企事通便民服务直通车：针对云谷开源与大模型特色园区，专员面对面开展算力券与2026首批Token券申请答疑，合规发票现场确认，避免企业因格式问题被退单。

## 资金/扶持或活动要点
现场直审直报最高 100 万元算力券额度 + 20%~50% Token 实付报销绿色通道

## 硬门槛 / 参与条件（去幻觉核验）
- 云谷中心及西湖区入驻企业（OPC 一人公司及 AI 初创优先）
- 已采购或近期拟采购智算裸金属、云算力或主流大模型 API 服务
- 备齐采购合同、对公转账凭证与发票原件/电子档

## 双益说明
- 助园：提升在园企业政策兑现确定性，现场增强企服专员与租户粘性，拉升二期扩租好感度
- 助企：省去来回跑腿与反复补件成本，当天出初审意见，资金申报周期缩短 60%
