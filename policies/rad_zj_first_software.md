# 浙江省首版次软件产品认定与研发应用推广支持

> 政策摘录样例，非正式全文。无已核验官网链接时仅供运营台演示对照。

**渠道**：政府政策  ·  **赛道**：资质与梯度培育
**文号/版本**：浙经信软件〔2025〕指南
**窗口/活动时间**：年度集中申报（每年 7~9 月）

## 一句话
基础软件/人工智能等首版次软件产品认定，最高给予 100~300 万元研发推广奖补

## 出处摘要
浙江省经信厅《浙江省首版次软件产品认定申报指南》：重点支持人工智能新兴软件、工业软件等方向，对经认定的首版次软件产品给予应用推广与首版次保险补偿支持。

## 资金/扶持或活动要点
省级首版次产品称号 + 最高 100~300 万元推广补助

## 硬门槛 / 参与条件（去幻觉核验）
- 产品属于人工智能、工业软件等年度重点指导目录范围
- 拥有自主软件著作权且产品经具有 CNAS/CMA 资质机构检测
- 产品具有明确的技术突破与商业化应用前景

## 双益说明
- 助园：树立园区自主可控核心技术标杆，争取省级软件名园授牌
- 助企：获得省级首版次权威背书，政府采购与央国企招投标享受倾斜
